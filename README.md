# StoryWeavers UI (Prototype)

Angular 19 user-interface prototype for StoryWeavers. The current routing redirects to a login screen. **Authentication is not implemented**; the login form is UI-only and must not be used to handle real credentials.

## Local development

    npm install
    npm start

Open http://localhost:4200/login.

## What exists

- Angular application with a login route
- PrimeNG login form components and initial styling
- Frontend-only scaffold

## What's missing

- Authenticated backend and session management
- Product workflows beyond the login screen
- Error handling, tests, secure storage and deployment configuration

This repository is an early UI experiment and not a working production application.
